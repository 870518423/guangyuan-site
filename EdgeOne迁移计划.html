阶段 0 · 准备（约 5 分钟）

作用：把"出错前"的状态留好后路。做完这些，就算后面全搞砸也能退回来。

当前 game-resource-forecast\deploy.zip（532KB，含 SW v6）。它的意义是"手动上线通道还在"，万一 Git 那条路走不通，你还能用老办法更新网站。
登录 dash.cloudflare.com → 选 m78calc.cn → DNS。当前是两条 A 记录：43.174.246.108 和 43.174.247.108。这两行是回滚的唯一依据，务必先截图。
https://github.com/870518423/guangyuan-site 应有 26 个文件。其中 edgeone.json 已写好：构建命令空、输出目录 .，迁移时不需要改任何配置。

阶段 1 · 新建 Git 项目（约 10 分钟）

作用：让云端多出一个"会自己盯着 GitHub 的"新网站项目。此时旧网站完全不受影响，风险为零。

入口：https://console.cloud.tencent.com/edgeone 。在左侧找到 Pages，点「创建项目」，三个选项里选 导入 Git 仓库。
会跳到 GitHub 页面点「Authorize EO Pages」。这一步是给 EdgeOne 一个只读密钥，它才有权限读代码。随时可以在 GitHub → Settings → Applications 里撤销。
你的网页是已经做好的成品 HTML，不需要编译打包，所以两个命令都必须留空。输出目录 . 表示"仓库根目录就是成品"。填错构建命令会直接构建失败。
这步关系要不要备案：选含中国大陆的节点，绑定自定义域名时会强制要求 ICP 备案，你目前没备案就会被拦；选"全球（不含中国大陆）"可直接绑定，代价是国内访问稍慢一点（与你现状一致）。
EdgeOne 会把仓库代码拉过去、铺到全球节点上。失败的话看构建日志，最常见原因是构建命令没留空或输出目录填错。

阶段 2 · 用临时域名验证（必须做）

作用：在动域名之前，先确认新项目真的是好用的。这一步做完之前，你的正式网站一个字都没变。

这是 EdgeOne 免费送的临时地址。它和你的 m78calc.cn 完全无关，随便玩都不会影响正式站点。
重点看样式有没有乱、图标能不能显示（四个阵营图标在 assets/factions/ 下）。
能搜到说明昨晚改的数据已经从这个仓库正确构建出来了；顺便检查「迫水真吾」的获得方式是不是「限时商店6000光元 / vip10礼包」。

阶段 3 · 切换域名（唯一有停机窗口的一步）

作用：把"门牌号"从旧项目挂到新项目。建议挑访问量低的时间做（比如深夜）。

同一个域名不能同时挂在两个项目上，所以要先摘下来。项目本身必须保留——它是你的回滚目标，里面的网页文件还在。
页面会告诉你该填什么（通常是一条 CNAME，或者新的 A 记录）。以页面上显示的为准，不要照抄我这里的旧 IP。
代理状态建议先设成灰色云「仅 DNS」，不要开橙色云。两层 CDN 叠在一起容易导致证书签发卡住，等稳定了再考虑。
你域名的 TTL 是 1800 秒。这段时间内网站可能短暂打不开或部分用户看到旧版，属于正常现象，耐心等。
EdgeOne 会免费自动签发证书。没签发完之前，浏览器可能提示"不安全"或证书不匹配，不要慌，等一会儿刷新。
现在别人输 www.m78calc.cn 是打不开的。填一条 CNAME 指向主域名即可消除这个尴尬。

阶段 4 · 验收

作用：确认从用户视角看，一切正常。

走移动网络能排除本地 DNS 缓存的干扰，测到的是真实用户看到的结果。
老访客手机里可能还存着 Service Worker 缓存（当前版本 v6）。强制刷新一次就能拿到最新内容。
证书为 m78calc.cn 签发、未过期即正常。
改某个页面里的一个字 → 双击「推送到GitHub.bat」→ 等 1~2 分钟 → 刷新网站看改动有没有出现。出现了就说明整条链路打通，这是本次迁移的终极目标。

阶段 5 · 之后日常（心态和习惯要改的地方）

作用：别把新流程和老习惯弄混。

不用再打包 zip、不用再登控制台上传。
Git 只管网页。安卓包里打包的是本地 www，仍需要 cap sync + 重新构建。改了网页就想让 App 也变，必须重新打一次包。
当前是 guangyuan-forecast-v6。虽然 HTML 已经是网络优先，但升版本号是最保险的"让所有老用户强制刷新"的手段。
它是免费域名，每 180 天要点一次续期。既然换成 .cn，就别再为它费心；它到期会自动失效，不影响新域名。
它是你的回滚目标。确认新流程稳定运行一段时间后再处理。

影响与风险一览

项目会发生什么
停机窗口仅切域名时，几分钟 ~ 30 分钟（取决于 DNS TTL）
HTTPS 证书自动重新签发，签发完之前浏览器可能告警
免费额度流量与请求不限，仅构建次数 500 次/月上限（你远远用不到）
安卓 App完全不受影响，也不会自动更新
分享链接不变，还是同一个域名
备案只要加速区域不选中国大陆，就不需要备案
回滚方案（万一新项目出问题）
1. 把 Cloudflare 里 m78calc.cn 的解析改回 43.174.246.108 / 43.174.247.108；
2. 在新项目里解绑域名，回到旧项目 guangyuan-forecast 重新绑定；
3. 旧项目的网页文件一直都在，内容不会丢，只是回到最后一次手动上传的版本。
