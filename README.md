# 奥系光元工具站

[![License: CC BY-NC 4.0](https://img.shields.io/badge/License-CC%20BY--NC%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc/4.0/deed.zh-Hans)

**在线地址：https://m78calc.cn**

一个公益性质的《奥特曼系列OL》玩家工具站。纯静态站点，支持 PWA（可「添加到桌面」离线使用），无需注册、无广告、不收费。

## 板块

| 板块 | 说明 |
| --- | --- |
| 光元收益预测器 | 按 30 天循环签到，支持按月、跨月乃至半年窗口预测收益 |
| 奥系人间体大全 | 4 大阵营人间体查询，支持点击名称互跳与反向查询 |
| 奥系攻略 | 修炼数值表、趣味问答题库（160 题）、社区转载攻略 |
| 角色被动版本收录 | 按阵营收录角色主动技与被动，可切换版本、开启相邻版本对比，改动处按「增强 / 调整 / 新增 / 移除」着色 |
| Android App | Capacitor 8 + Android 原生壳，完整源码位于 [`apk-project-v2/`](apk-project-v2/)，支持离线核心与内容热更 |

## Android App

完整 Android 源码位于 [`apk-project-v2/`](apk-project-v2/)。当前公开安装包为 `v0.2.2-r2`，构建步骤、权限说明、APK SHA-256 与签名证书 SHA-256 均在该目录的 README 中。

- Android 清单仅申请网络权限（`INTERNET`）。
- 不申请通讯录、定位、相机、麦克风、短信、通话或外部存储权限。
- Android 工程已从公开源码在本地成功编译 Debug APK；Actions 构建配置已随源码保存，待补充推送令牌的 `workflow` 权限后启用。
- 签名证书与密码不会进入仓库。
